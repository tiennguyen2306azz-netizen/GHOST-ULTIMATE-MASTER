# GHOST-ULTIMATE-MASTER 🚀

**GHOST-ULTIMATE-MASTER** là một ứng dụng AI để bàn (Desktop App) cục bộ, hiệu năng cao, được thiết kế chuyên biệt cho nghiên cứu An ninh mạng chuyên sâu, giải đấu CTF và giải thuật phức tạp.

## 🌟 Tính năng nổi bật
- **⚡ Chế độ Master Mode:** Trí tuệ không giới hạn, chuyên trị các mảng Pwn, Reverse Engineering, Crypto và Web Exploitation.
- **▶ GHOST-SANDBOX:** Tích hợp môi trường thực thi mã Python trực tiếp để kiểm tra kết quả ngay lập tức.
- **🧪 Phân tích chuyên sâu (Deep Analysis):** Suy luận đa tầng để giải quyết các bài toán hóc búa nhất.
- **🌐 Tìm kiếm Web:** Truy cập Internet thời gian thực để cập nhật các CVE mới nhất và dữ liệu kỹ thuật.
- **🔊 Giọng nói AI:** Tích hợp chuyển đổi văn bản thành giọng nói (TTS) để tương tác rảnh tay.
- **🔍 Thị giác máy tính (Vision):** Phân tích hình ảnh đa phương thức cho OCR và giải quyết các vấn đề trực quan.

## 🛠 Công nghệ sử dụng
- **Python 3.x**
- **CustomTkinter:** Giao diện hiện đại, mượt mà và trực quan.
- **Cloud AI Models:** Sức mạnh trí tuệ nhân tạo từ các mô hình ngôn ngữ lớn nhất.
- **DuckDuckGo Search:** Tích hợp tìm kiếm thời gian thực.
- **Pyttsx3:** Tổng hợp giọng nói ngoại tuyến.

## 🚀 Hướng dẫn cài đặt

### Yêu cầu hệ thống
- Python 3.10 trở lên
- Mã API Key (Liên hệ quản trị viên hoặc sử dụng nhà cung cấp của riêng bạn)

### Các bước cài đặt
1. Clone repository này:
   ```bash
   git clone https://github.com/tiennguyen2306azz-netizen/GHOST-ULTIMATE-MASTER.git
   cd GHOST-ULTIMATE-MASTER
   ```
2. Cài đặt các thư viện cần thiết:
   ```bash
   pip install customtkinter openai requests Pillow duckduckgo-search pyttsx3 python-dotenv
   ```
3. Tạo một file tên là `.env` trong thư mục gốc và thêm mã API key của bạn:
   ```env
   GHOST_API_KEY=ma_api_key_cua_ban_o_day
   ```
4. Khởi chạy ứng dụng:
   ```bash
   python ghost_ai.py
   ```
