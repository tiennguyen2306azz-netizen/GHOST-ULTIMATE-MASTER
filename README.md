# 🛡️ GHOST-ULTIMATE-MASTER: Elite AI Security OS 🚀

**GHOST-ULTIMATE-MASTER** là nền tảng trí tuệ nhân tạo local thế hệ mới, được tối ưu hóa tối đa cho các chuyên gia bảo mật, vận động viên CTF và nhà phát triển phần mềm cao cấp. Không chỉ là một chatbot, GHOST là một trợ lý thực thụ có khả năng suy luận, chạy code và truy tìm lỗ hổng.

---

## 💎 Tính năng "Độc bản" chỉ có trên GHOST

### ⚡ 1. Master Mode (Unrestricted Intelligence)
Chế độ "Vô cực" cho phép AI phá bỏ mọi rào cản lọc thông tin thông thường. Master có thể yêu cầu AI viết các script khai thác lỗi (Exploit), phân tích mã độc (Malware Analysis) hoặc giải các thử thách Pwn/Reverse cực khó mà không bị từ chối.

### ⚙️ 2. GHOST-SANDBOX (Integrated Execution)
AI không chỉ viết code, nó có thể **chạy code**. Khi AI sinh ra mã Python, hệ thống sẽ tự động kích hoạt môi trường Sandbox an toàn để Master thực thi và xem kết quả ngay lập tức chỉ với 1 cú click.

### 🧪 3. Deep Analysis Mode
Kích hoạt tư duy đa tầng (Chain-of-Thought). AI sẽ tự phản biện logic của mình qua 3 bước: Phân tích bài toán -> Đề xuất giải pháp -> Kiểm tra lỗi ngoại lệ. Thích hợp cho các thuật toán mã hóa và tối ưu hóa hệ thống.

### 🔊 4. AI Voice & Real-time Vision
- **Voice:** Giao tiếp bằng giọng nói tự nhiên, giúp Master rảnh tay khi đang thực hiện các tác vụ kỹ thuật.
- **Vision:** Nhận diện mã nguồn qua ảnh chụp màn hình, giải bài toán trên giấy hoặc phân tích sơ đồ mạng qua hình ảnh đính kèm.

## 🚀 Hướng dẫn triển khai nhanh

### 📋 Yêu cầu hệ thống
- Hệ điều hành: Windows 10/11, Linux hoặc macOS.
- Python: Phiên bản 3.10 trở lên.

### 🔧 Cài đặt trong 3 bước
1. **Clone & Mở thư mục:**
   ```bash
   git clone https://github.com/tiennguyen2306azz-netizen/GHOST-ULTIMATE-MASTER.git
   cd GHOST-ULTIMATE-MASTER
   ```

2. **Cài đặt thư viện:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Cấu hình bảo mật:**
   Tạo file `.env` tại thư mục gốc và dán mã API vào:
   ```env
   GHOST_API_KEY=ma_so_bi_mat_cua_ban
   ```

4. **Khởi chạy:**
   ```bash
   python ghost_ai.py
   ```
